# 0006 — Worktree 使用已有分支

日期 2026-11-10  
状态 已接受

## 背景

除了从基线创建新分支，用户也可以在独立目录中使用一个空闲的已有分支，主目录保留当前检出。Git 只允许同一分支同时检出到一个 worktree，主目录也计入。

## 决策

分支面板顶部提供「新分支｜已有分支」，默认选中「新分支」。主按钮统一为「创建 Worktree」。

- 「新分支」从列表选基线，并按 0005 填写或自动生成分支名。
- 「已有分支」要求明确选择目标。正在使用的本地分支禁用。远程分支在没有同名本地分支时可选，创建时使用已有的远程跟踪引用建立同名本地分支，并设置上游。如果创建前同名分支已出现，则拒绝请求。
- 分支状态刷新后保留已选目标。目标不可用时，提示用户重新选择。
- 两种方式都保留文件复制和创建后打开工作区的行为。目录名取本地分支名并按 0003 处理。

新分支模式继续使用 Git 配置 `branch.<name>.dsh-worktree-base` 识别。已有分支模式的标记保存在对应 worktree 的 Git 注册目录，读取时优先使用该标记。Git 移除注册时会一并移除标记。

已有分支模式的提交直接进入检出的本地分支。会话头部只显示分支名和删除入口，删除 worktree 时保留该分支。插件合并接口对此模式返回 `noBase`。
